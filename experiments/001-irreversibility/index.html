001 · irreversibility

Hypothesis. The HPP gas is a reversible bijection with a strict light cone, so any arrow its states show must come from the initial condition and the partition, not the law: entropy rises from a packed block into the equilibrium band, the exact echo returns the state bit for bit, and one flipped bit destroys the reversal while the naive flip-only reversal fails to retrace. Pre-registration: README.

Why “reverse” needs an order

A small teaching control for Q4: microscopic reversibility is not a preferred arrow of time. Start with two particles on a periodic 4 × 4 square. Change only the west particle’s position; every return recipe starts from the same forward state. The lattice speed limit is one cell per step.

Write collision as C, streaming as S, and velocity flip as R. A forward step is S ∘ C (read right to left). Undo it in the opposite order: C ∘ S⁻¹. Flipping velocities, stepping forward, and flipping again gives S⁻¹ ∘ C instead. The corrected flip also collides: G = C ∘ R; then G ∘ step ∘ G is the exact inverse.

Existing proof and what this check means

Proved: step_inverse and loschmidt_echo in TimesArrow/Claims.lean. The echo proof applies Function.involutive_conj_echo: G applied twice is the identity, and conjugating one forward step by G undoes it; induction extends this to any number of steps.

Verification: the cards read back integer states from the existing GPU kernel, not an animation model. Any nonzero bit difference for the exact or corrected return fails this teaching check. The separated control predicts 0 differences for all recipes; the head-on pair predicts 4 for flip-only. These two finite examples do not prove GPU equivalence or settle Q4, and make no continuum or entropy claim.
